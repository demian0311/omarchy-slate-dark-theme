# Slate art backgrounds

Public-domain artworks and photographs, converted to greyscale and gradient-mapped
onto ramps built from the Slate palette. Each image keeps a neutral slate spine and
spends exactly one theme accent, so the set showcases the palette without any single
wallpaper becoming a rainbow.

| File | Source | Accent |
|------|--------|--------|
| `great-wave` | Katsushika Hokusai, *The Great Wave off Kanagawa* (c. 1831) | blue `#5b9bd5` |
| `starry-night` | Vincent van Gogh, *The Starry Night* (1889) | yellow `#d9bd5a` on blue |
| `red-fuji` | Katsushika Hokusai, *Fine Wind, Clear Morning* (c. 1831) | cyan `#45b3a3` |
| `tetons` | Ansel Adams, *The Tetons and the Snake River* (1942) | orange `#e0975a` |
| `canyon` | Ansel Adams, *Grand Canyon National Park* (1941–42) | magenta `#a585c9` |

Hokusai and van Gogh scans via Wikimedia Commons; the Adams photographs are US
National Archives records (79-AA series), public domain as federal works.

Regenerate with `~/.local/share/slate-backgrounds/slate-art-backgrounds.sh` (sources kept alongside it).
